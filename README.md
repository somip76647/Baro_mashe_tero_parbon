# Baro_mashe_tero_parbon
Bengali festival tracker with countdown timers for all major Hindu festivals (Durga Puja, Kali Puja, Saraswati Puja, Lakshmi Puja, Dol Jatra, Rath Yatra, Janmashtami, etc.). Features daily panjika, puja checklists, notifications, and Spotify/YouTube music links. Built with Next.js, TypeScript, Tailwind CSS.



# ১২ মাসে ১৩ পার্বণ

Bengali festival tracker with countdown timers for all major Hindu festivals.

## Features

- 🎉 All major Hindu festivals (Durga Puja, Kali Puja, Saraswati Puja, Lakshmi Puja, Dol Jatra, Rath Yatra, Janmashtami, Vishwakarma Puja, Nabanna, Pohela Boishakh, etc.)
- ⏱️ Live countdown (days, hours, minutes, seconds)
- 📅 Daily panjika (Bengali & English)
- ✅ Puja preparation checklist
- 🔔 Special day notifications
- 🎵 Spotify/YouTube music links
- 🌍 Time zone support (Local, BD, IN)
